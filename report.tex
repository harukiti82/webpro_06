\section{目的}

これまでの授業で，Express（Node.js）を用いた Web アプリ \texttt{app5.js} を作成してきた．
このアプリは，京葉線の駅一覧・残念なポケモン図鑑・最強剣一覧・特殊羽一覧といった
複数の一覧を 1 つのサーバーで提供するものである．

本課題の目的は，これとは別に React で制作したゲーム「マインスイーパー」を，
この既存の Web アプリへ統合し，\textbf{Azure 上の同一サーバーから URL を入力するだけで
ブラウザ上で遊べるようにする}ことである．具体的には，次の 2 点を実現する．

\begin{itemize}
  \item マインスイーパーを \texttt{http://<サーバーの IP>:8080/minesweeper/} で公開し，
        ブラウザから直接アクセスして遊べるようにする．
  \item トップページ（一覧メニュー）からもマインスイーパーへ遷移できるようにし，
        ゲーム画面からはトップページへ戻れるようにする．
\end{itemize}

マインスイーパー本体はあらかじめ静的ファイル（HTML・JavaScript・CSS）としてビルドしておき，
サーバー側（\texttt{app5.js}）からその静的ファイルを配信する構成とした．
これにより，サーバー側では新たなライブラリを追加することなく，
既存の Express の仕組みだけでゲームを公開できる．
